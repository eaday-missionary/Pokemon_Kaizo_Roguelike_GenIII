# Pokemon Roguelike Gen 3

A local Generation III Pokemon battle game derived from Pokemon Showdown.

## Run

Install Node.js 22.18 or newer, then run:

```sh
cd server
npm install
npm run build:local
npm start
```

Open http://127.0.0.1:8080/ in your browser. After setup, Windows users can also use `Start Local Battles.cmd`.
